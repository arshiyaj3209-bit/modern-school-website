# Modern School Website

A modern and responsive school website developed using HTML5, CSS3, and Bootstrap 5. This project was created as a front-end web development project with a focus on clean design, responsive layouts, structured content, and a professional academic experience.

## 📌 About the Project

The Modern School Website is designed to represent a contemporary educational institution and provide visitors with an organized way to explore the school's academics, campus, admissions, facilities, and other important information.

The website uses a clean navy-blue visual theme combined with light backgrounds, structured sections, cards, icons, images, statistics, and responsive layouts. The goal was to create an interface that feels professional while remaining easy to navigate across different screen sizes.

## ✨ Features

- Responsive navigation bar
- Modern homepage design
- School introduction and information
- Academic programs and sections
- Primary, Middle, and Senior School pages
- Curriculum information
- Campus Life section
- Admissions and application information
- Assessment and interview information
- Key admission dates
- Fees and financial information
- School statistics
- Facilities and student-focused sections
- Responsive layouts using Bootstrap 5
- Custom CSS styling
- Image-based visual sections
- Clean and consistent design system

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
- Bootstrap Icons

## 📱 Responsive Design

The website is designed to adapt to different screen sizes, including desktops, laptops, tablets, and mobile devices. Bootstrap's responsive grid system and custom CSS were used to maintain consistent layouts throughout the website.

## 🎯 Project Goals

The main purpose of this project was to strengthen practical front-end development skills and understand how individual web pages can be combined into a complete, structured website.

The project also provided hands-on experience with responsive design, reusable components, navigation systems, page layouts, typography, spacing, visual hierarchy, and organizing a larger front-end project.
